Claude Code 참조용 스펙 (mm, 베이스 좌표계)

# UR5e workcell — units: mm  (UR/ROS API는 m 단위이므로 1000으로 나눠 사용)
# origin = 로봇 베이스 장착면 중심 (플레이트 상면), 바닥 기준 870
# +X: 베이스 중심 → workspace 방향, +Z: 위쪽
units: mm

given:                                # 사용자 지정 기준치수
  base_to_workspace_edge_x: 210      # 베이스 중심 → workspace 끝단(프로파일 바깥면)
  base_to_workspace_surface_z: -37.5 # workspace 상면이 베이스보다 37.5 낮음

robot:
  model: ur5e
  base_mount_height_from_floor: 870    # 860 지지대 + 10 플레이트
  mount_plate: {size: [210, 210, 10], base_at: center}
  pedestal: {height: 860, footprint: [210, 210]}   # footprint 가정

workspace:
  profile_width: 40
  surface_z: -37.5                     # 바닥 기준 832.5
  frame_x: [210, 790]                  # 전체 580 (40+500+40)
  frame_y: [-625, 625]                 # 전체 1250 (40+1170+40)
  inner_x: [250, 750]                  # 실제 작업영역 500
  inner_y: [-585, 585]                 # 실제 작업영역 1170
  inner_size: [500, 1170]
  center: [500, 0, -37.5]

tcp_bounds_suggestion:
  x: [250, 750]
  y: [-585, 585]
  z: [-37.5, 400]                      # 하한 = 작업면, 상한은 태스크에 맞게 조정

해석 및 가정  Assumptions

  1. 210 = 끝단까지 — 베이스 중심에서 workspace 끝단(근접측 프로파일 바깥면)까지의 수평거리로 확정 반영했습니다. 따라서 프로파일이 X 210~250, 실제 작업영역은 X 250~750입니다.
  2. 37.5 = 높이차 — 베이스 장착면(Z=0, 바닥 +870)보다 workspace 상면이 37.5 낮습니다. 즉 workspace 상면 Z = −37.5, 바닥 기준 832.5.
  3. 간극 105는 계산값 — 지지대 단면을 플레이트와 같은 210×210으로 가정했을 때 지지대 바깥면(X 105)과 workspace 끝단(X 210) 사이에 생기는 여유입니다. 지지대 실제 폭이 420을 넘으면 workspace와 간섭합니다.
  4. Y 1250 — 프로파일 포함 전체 길이로 해석해 40+1170+40으로 나눴습니다. 1250이 안쪽 작업영역이라면 전체는 1330이 됩니다.
  5. Y 대칭 — 베이스 중심을 지나는 X축에 대해 좌우 대칭(±625)으로 가정했습니다.
  6. 프로파일 높이 — 프로파일 상면이 작업면과 같은 평면이라고 가정했습니다. 40 높이로 솟은 테두리라면 측면도 수정이 필요합니다.
